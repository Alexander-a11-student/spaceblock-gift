# SpaceBlock — цифровой подарок

Сайт: https://alexander-a11-student.github.io/spaceblock-gift/

Готовая статическая страница для GitHub Pages. Регистрации, серверного приложения, базы данных, аналитики и внешних шрифтов нет. Код Android-приложения и Minecraft-мода не меняется.

## Публикация

GitHub Pages публикует корень ветки `main`. APK, JAR и `SHA256SUMS.txt` хранятся в GitHub Releases, в релизе `gift-2026-11-01`. Большие бинарные файлы в Git не добавляются.

Страница содержит прямые ссылки на эти вложения релиза. Названия файлов и тег нужно сохранять, чтобы ссылки продолжали работать.

## QR для печати

`print/SpaceBlock-QR.png` — чёрно-белый PNG 1952 × 1952 пикселя с коррекцией ошибок H и белой рамкой. Адрес внутри QR совпадает с адресом GitHub Pages. Печатайте размером от 40 × 40 мм, сохраняя белое поле и пропорции.

Для генерации QR через Node.js: `npm install`, затем `npm run qr -- https://alexander-a11-student.github.io/spaceblock-gift/`.

Первоначальный PNG создан и проверен обратным декодированием с ZXing 3.5.3, уже включённым в исходный JAR мода. `scripts/MakeQR.java` позволяет повторить эту проверку.

## Файлы сайта

- `index.html` — контент, ссылки и инструкции.
- `style.css` — адаптивное оформление и поддержка reduced motion.
- `assets/spaceblock-logo.png` — существующий логотип SpaceBlock из проекта Android.
- `scripts/upload-release.mjs` — локальный загрузчик: получает авторизацию через Git Credential Manager, не сохраняет и не печатает токен. Используется вместе с локальным, исключённым из Git `scripts/release-state.json`; файлы берутся из родительской папки сайта. После успешной загрузки трёх файлов публикует черновик релиза.
